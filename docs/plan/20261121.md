# BookCars 入境游客用车首发计划

日期：2026-11-21。代码基线为 BookCars `9.7.0`（`3034aad5`），含已完成的日期费率结账修复。对标依据公开资料，实际接待条件以合作门店确认结果为准。

## 首发做什么

**服务来中国大陆旅行、希望租车自驾的境外游客。** 首发以一个入境城市、一家已确认能接待境外旅客的合作门店、固定地点取还车为试点假设。复用现有手机网页和后台，用英文服务游客、中文服务门店。优先验证游客能否提前确认资格、看清价格、使用境外联系方式预订，以及抵达后能否顺利取车。

**游客流程**：选车和日期 → 查看门店证件要求及费用 → 用邮箱和境外手机号提交 → 收到门店确认与英文取车指引 → 到店验原件、付款和取车 → 还车及结算。首发建议采用门店人工确认、到店付款，前提是门店已验证可接受的境外卡和押金方式。机场接送或带司机用车可视为后续独立服务，首发可由客服转介具备相应资质的合作方。

## 对标悟空租车和一嗨租车

| 对标 | 公开能力及边界 | 首发要补的差距 |
| --- | --- | --- |
| 悟空租车 | 多供应商比价，车型页展示基础保障和可选保障。所查公开首次取车问答以大陆身份证及国内驾驶证为例，境外护照和临时许可的接受情况需向具体商家确认 | 借鉴车型、费用、保障、取车条件的展示方式。让每个试点取车点有明确的外籍旅客接待规则，并在提交前展示。 [悟空官网](https://www.wkzuche.com/) · [取车问答](https://m.wkzuche.com/wenda/1961689.html) |
| 一嗨租车 | 直营门店的预订和交付流程。官方帮助中心为外籍人士列有护照、中国有效驾驶证及本人信用卡等条件。短期游客持临时驾驶许可是否可取车需逐店核实 | 借鉴门店交付清单、本人付款卡及押金提醒、取消和保障说明。把门店确认结果、取车地点和客服联系方式写进英文确认邮件。 [一嗨帮助中心](https://www.1hai.cn/Help/HelpContent?isLimitRules=False&menuId=12) |

短期访客使用境外驾照在中国大陆自驾，应先取得适用的中国临时机动车驾驶许可，并核对准驾车型和有效期。护照、境外驾照、中文译件和国际驾照（IDP）均不能单独代替中国驾驶许可。按试点城市整理官方办理地点、预约方式和材料，按门店核对取车条件。平台提供办证信息，许可由公安交管部门签发。 [管理规定](https://www.shanghai.gov.cn/grjszywgjj/20240826/3c73b5e4a7544a2aa382f7cdb6b38916.html) · [北京办事指引示例](https://jtgl.beijing.gov.cn/jgj/93950/jwgk/jsrgl/203470/index.html)

## 核心开发清单

| 顺序 | 做什么 | 验收标准 |
| --- | --- | --- |
| 1. 门店与英文指南 | 在现有地点、车辆详情和结账页展示试点门店的双语地址、营业时间、固定取还点、收费与保障、可接受证件和付款卡；对尚未取得许可的游客提供办证链接及人工协助入口 | 游客从手机网页能找到取车点、准备材料、了解总价和押金。合作门店书面确认接受的证件和卡种。 |
| 2. 游客预订与人工确认 | 复用游客结账，以邮箱和含国家区号的手机号联系。只记录证件类型、是否已具备中国驾驶资格及必要的核验结论。申请及邮件标明「待确认」。后台用 `Reserved` 确认订单，启用试点车辆占位，并在服务端校验同店取还、门店营业时间、车辆档期和人民币报价；时间统一按 `Asia/Shanghai` 展示和核算 | 使用非 `+86` 号码可提交并收到结果。海外时区访问仍显示同一个北京时间取车时刻。两人申请同一辆车的重叠档期时，只能确认一笔。取消后档期可重新预订。 |
| 3. 到店核验和取还车 | 门店验有效护照及适用的中国驾驶证或临时许可，核对准驾车型、有效期和租期。用现有后台记录已取车、已还车和异常，留存合同版本、车辆里程、油量/电量和车况，提供英文客服联系途径。确有保存证件的义务时，先明确处理依据及保存期限，再使用授权访问和私有存储 | 许可未取得、过期或车型不符时无法确认交车。游客能按邮件提示找到门店，工作人员能核对取还车记录。 [个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm) |
| 4. 到店付款与售后 | 门店实测境外卡付款、押金或预授权、释放和退款。页面分别列出租金、保障、押金和取消费用。后台保留订单号、收款/退款金额、付款凭证参考号和状态，发票由约定主体按需处理 | 用一张明确支持的境外卡走通真实小额收款和退款，订单金额与凭证一致。客户取消或无法取车时，门店可按页面所示政策处理。 |

首期排期为**先核实门店，再开发和联调，最后实地跑单**。上线前至少完成三条演练：正常预订取还车、证件不合格无法取车、取消退款。额外验证公开证件链接已关闭、英文邮件能送达，以及预订从境外和境内手机网络均可完成。门店可用车源、证件规则、收款/押金方式和英文客服负责人是上线前需确认的运营条件。

## 试点后再评估

信用免押、异地还车、上门送取、国内钱包、小程序、多供应商结算和自动开票放入试点积压。优先根据实际订单的资格咨询量、申请确认率、取车失败原因和境外卡支付成功率决定下一批工作。若试点后来开启线上预付，应先解决现有浏览器回跳依赖、支付失败后的订单一致性和退款恢复，再用实单验证通道。 [Stripe 回跳](../../frontend/src/pages/CheckoutSession.tsx) · [结账中的移动端扣款](../../backend/src/controllers/bookingController.ts)
